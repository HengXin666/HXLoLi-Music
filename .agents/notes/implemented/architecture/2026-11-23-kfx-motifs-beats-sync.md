## Decision

- 同目录同次改动: kfx_art.py, kfx_sync.py (新), kfx_build.py (读 beats.json, 跑物象), kfx_design.py (物象 字段), kfx_verbs.py (迸), kfx_test.py, kfx_README.md.

- kfx_sync.py (通用工具): `lag` 用人声分轨逐 mora 找频谱通量峰, 按行取中位数, 标出连续偏慢的段; `fix` 只移偏差超阈值的行 (整行, 最多 0.2 s, 先备份 timing.json); `beats` 逐拍跟踪伴奏通量 (固定 bpm 网格在本曲 100~140 s 漂了 0.09 s), 底鼓最强的相位定小节头, 写 beats.json. 本曲 fix 移了 20 行.
- kfx_art.py: 物象的图. 简单道具在代码里画 (茶杯 汽 瓣 心 星 花 云, 颜色取自 ED 画面); 复杂的从画面抠图 (rembg isnet-anime) 后 `trace` 成颜色层 (先降色, 层数 ~100). 每层带共享包围盒 (`m 0 0 m W H`), 多层在任何 \an / \fsc 下对齐 (libass 按包围盒对齐绘图, 实测).
- 不用 \1img: 只有定制 libass 渲染, ffmpeg 预览和 kfx_check 看不到, 无法验收.
- kfx_motif.py: 物象 伴 / 游 / 洒 + 补丁动作 迸. 时间全部取自拍网格: 冲击在拍上, 蓄力在拍前, 小节头更重, 规律可预测 (左右交替, 落点轮流). 限制在歌词框外扩 5% (BOX), 不压字.
- design.md 新字段 `物象` (之前被校验器拒绝, 现在按 MOTIFS 校验名字和图); kfx_test T3 改为拒绝未知物象.
- kfx_README: 坑 3 改写 (字上动作为主, 物象点缀的条件), 新坑 13 卡点, 14 字慢自查; 换歌第 0 步量时间; 物象表与抠图描图流程.

## Alternatives considered

- 什么都不做: 用户明确要求物象 / 粒子 / 卡点, 不取.
- 复用现有方案 (オンリー 的 wd/objs 手描物象): 那是单曲脚本, 时间写死秒数, 不踩拍, 不能给下一首用, 不取.
- \1img 贴图 (点兔 的做法): 见上, 验收链路看不到, 不取.

## Consequences

- 每首新歌先跑 `kfx_sync.py beats` / `lag`; 物象与 迸 依赖 beats.json (没有时退回 `拍` 固定网格).
- 物象会增加事件数 (本曲 52k -> 56k); 描图层数要控制, 层数 x 拍数 = 事件数.
- kfx_check K2 仍是越界门禁; 物象按固定 BOX 自限, 不依赖 K2 放宽.
- 金样 (オンリー) 不用物象, 逐字节不变.
