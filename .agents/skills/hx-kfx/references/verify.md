# 验收

`python kfx_check.py <工程> --render --fonts <字体目录>`, 退出码 0 才算过:

| 门禁 | 判据 |
|---|---|
| G1 timing | 每个日文单元与每个振假名音拍的已唱层起点 = timing.json 起点 (±15ms) |
| G2 bilingual+ruby | 每句有中文; 每个含汉字的单元有注音 |
| G3 one line | 相邻两句的未唱 / 已唱 / 光晕层同屏重叠 <= 0.08s |
| G4 band | 所有 `\pos` / `\move` 的 y 在 600..1080 (片头字卡除外) |
| G5 palette | 已唱比未唱亮 (其余配色规则在方向文件校验里) |
| G6 render | libass 实渲每句中点, 字幕带内有足够亮像素 |

## 抽帧目检 (门禁之后, 不可省)

1. `preview --lines` 整张联系表: 每句的颜色是否就是那一刻画面的颜色; 字是否压在画面主体上
2. 每个名场面抽连续帧 (0.2s 间隔, 裁到字幕带): 裂纹是否从字处炸开, 红线是否跟着唱, 魔法阵是否在字下面而不是压字
3. 换行处抽 3 帧: 旧行是否已经在走, 新行是否没有和旧行叠成一团
4. 雪景 / 白场 / 金光这些最亮的段落: 未唱字是否仍读得出

看到问题改方向文件重跑, 不要手改 ASS.
