# 设计方法: 从一首歌读出方向文件

以 無職転生 ED1「オンリー」(大原ゆい子) 为例. 成品: `dev/无职转生/オンリー/direction.kfx.json`.

## 1 先看 MV, 逐句记画面 (不许凭印象)

`python kfx_preview.py <ass> --video base.mp4 --fonts <dir> --lines` 给每句中点一帧.
第一遍可以先用任意方向文件生成一份, 只为拿到 "每句对应哪一帧". 逐句写: 场景, 主色, 人物, 光线.

オンリー的 MV (PCS Studio 剪辑) 是鲁迪成长的回忆蒙太奇, 逐句读出来是:
雪中的幼年鲁迪 -> 夜林光点 -> 草原远景 -> 夕阳屋顶 -> 静谧草原 / 艾莉丝红发 -> 洛琪希在草原举杖 -> 魔法漩涡
-> 石墙花园 -> 落叶天空 -> 暗蓝窗帘 -> 夜麦草 / 艾莉丝与鲁迪对视 -> 粉色云海 -> 洛琪希魔女帽 -> 仰望天空 -> 交握的手
-> 火 -> 冰像碎裂 -> 逆光金色 -> 烛台 -> 琥珀室内 -> 光斑 -> 金色麦田 -> 艾莉丝与鲁迪在风里 -> 白场 -> 红藤墙前挥手.

## 2 读懂歌: 三个问题

1. **番剧背景**: 前世是 34 岁家里蹲, 这一世 "这次要认真活". 关键人物与符号: 洛琪希 (师父, 水魔法, 蓝), 艾莉丝 (红发, 剑, 狂犬), 希露菲 (风, 绿), 保罗 (剑).
2. **歌词意境**: "学会了爱的入门却握不住" -> "想要破坏 / 想要守护 / 想要隐藏" 三次同构的副歌 -> 桥段自问 "为了你? 为了自己?" -> "唯有你".
3. **作者意图**: 曲名オンリー = "唯一". 告白对象 "貴方" 从师父到家人到唯一的她, 随画面移动. 所以全曲的收束符号只能有一个: 一根红线, 只在 "貴方" 出现时画.

## 3 落成方向文件的三样东西

**段落** (sections): 每段 = 一个情绪 + 一段画面. 颜色取画面主色, 情绪决定进退场:
| 情绪 | 进场 | 退场 |
|---|---|---|
| 孤独, 冷, 内省 | ink | dissolve |
| 走出去, 风 | wind | wind |
| 温暖, 信任 | drift | rise |
| 爆发, 破坏 | flash | shatter |
| 隐藏 | ink | veil |
| 抹去 | ink | erase |
| 终章 | ink | white |

**关键词** (words): 全曲固定的强调色, 日文和中文对应词同色. オンリー: 貴方 (玫红, 红线色), 壊 (红), 守 (水蓝), 涙 (淡蓝).

**名场面** (moments): 每段最多一个, 必须对得上词义. 同构句用同一骨架换材质:
第一次 "壊したい" 红色裂纹 + 火星, 第二次舞会玫红 + 花瓣, 第三次冰蓝 + 冰片 (那一刻画面正是冰像碎裂).

## 4 自查

- 每段的 scene 写的是你在抽帧里看到的, 不是番剧简介
- 每个 why 能回答 "为什么是这个, 不是别的"
- 把方向文件给别人看, 他能不看 ASS 就说出副歌长什么样
