# 输入格式

## lyrics.txt

```
# 注释行
00:26.586 | [愛|あい]のイロハを[学|まな]んでも | 纵然学会了爱的入门
00:39.140 | {(If you do)|いふゆーどぅ} なんだって[怖|こわ]くないから | 无论面对什么 我都不再害怕
```

- 第二列日文: `[漢字|かな]` 是一个带注音的单元; `{(English)|かな}` 是一个英文单元 (用 lat 字体, 不注音); 其它每个字符一个单元; 空格只是视觉间距; 标点 (？！、。) 附在前一个单元上, 不计时
- 第三列中文翻译; 第一列时间只是参考, 时间以 timing.json 为准

## timing.json

`[{"line": 0, "unit": 0, "mora": 0, "text": "あ", "s": 25.947, "e": 26.147}, ...]`

- 每个单元的音拍数 = 它的读音; 振假名会按音拍逐个点亮, 前提是音拍文本拼起来等于注音
- 生成器在单元数对不上时直接报错并列出该句的单元, 先修数据再生成
