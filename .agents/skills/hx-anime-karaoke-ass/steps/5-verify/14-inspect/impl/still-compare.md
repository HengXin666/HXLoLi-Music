# still 对照: 与原版逐帧并排

## 只做这一件事

把**原版**与**本工程产物**在同一时刻各渲一帧, 并排成一张图. 用来回答"像不像", 以及"差在哪一帧".

**它是 14-inspect 的补充, 不是替代**: `14-inspect` 看的是"自己的产物有没有低级错误";
still 对照看的是"与原版的距离". 两者判据不同, 都要做.

## 什么时候需要它

| 场景 | 要不要 still 对照 |
|---|---|
| 复现/仿制某个已有成品 | **必须**. 没有对照就没有"差多少"的客观读数 |
| 自己从零设计 | 不需要原版, 但需要**同一句的多版本对照**(如换字体前后) |
| 只改了一句 | 只对那一句做, 不必全曲 |

## 命令

```bash
# 1) 两侧各渲一遍. --times 用同一组时刻, 便于并排
hx-karaoke render_octopus.py 原版.ass  --times 6.2,6.6,7.0,7.4 --fontsdir "$(hx-karaoke --fonts)" --out review/still/ref/
hx-karaoke render_octopus.py proj/out.ass --times 6.2,6.6,7.0,7.4 --fontsdir "$(hx-karaoke --fonts)" --out review/still/new/

# 2) 并排(左原版 右新版), 裁到字幕带后放大
hx-karaoke still_compare.py --ref review/still/ref --new review/still/new \
    --out review/still/cmp --crop 540,880,1380,1050 --label "ORIGINAL" --label2 "MINE"

# 3) 出对比视频(把并排帧串起来)
ffmpeg -framerate 12 -i review/still/cmp/%03d.png -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" \
    -c:v libx264 -pix_fmt yuv420p -crf 16 review/still/compare.mp4
```

## 判据(三条, 都能机械算)

### 1. 分区像素比: 每区都在 1.15 以内

把画面按语义分三带  **盘/装饰区 / 字区 / 注音区**, 各带独立统计非背景像素数,
再算 `新版 / 原版` 的比值.

```bash
hx-karaoke still_compare.py --ref review/still/ref --new review/still/new \
    --bands "disc:935:1040:560:1360,text:975:1020:560:1360,ruby:898:972:560:1360"
```

**阈值 1.15**: 小于 1.15 说明两边的"量"一致, 差异只在形状/相位. 超过 1.15 就是
某一区多了或少了一整类东西(漏画一个图案、注音没出、装饰多一层).

**分区的意义**: 全局像素差会被大面积的装饰冲掉. 分区之后, 一个区的偏差会立刻暴露它属于哪一层.

### 2. 包围盒: 两侧的 x 范围必须同宽

```bash
hx-karaoke still_compare.py ... --bbox
```

判据: 每帧的 `[x0, x1]` 与 `[y0, y1]` 在两侧**相差 ≤ 2px**.

差得多说明**几何基准不同**, 不是画得不像  常见原因是字体不同(字宽不同 → 整行宽度不同),
或 `line.left` 的计算口径不同. 这一条能立刻把"几何错"与"形状错"分开.

### 3. 逐帧时序: 每个区域的变化时刻要对齐

对每个区, 看它的像素量随时间怎么变. 突变时刻(涨/跌超过 30%)两侧应对齐.

**这一条抓的是编排错误**: 该退场不退、该入场不入、逐字相位差一拍.

## 一条实测教训

**只看单帧会漏掉纯时间域的问题.** 实测一份产物砍掉"33ms 弹跳"后, 单帧像素差为 **0** 
单帧根本看不见它. 所以 still 对照**必须配一条 `--times` 覆盖整句的序列**(至少覆盖
入/中/出三个时刻), 只挑一帧"最好看的"来比等于自欺.

## 与盲审的分工

| 步骤 | 输入 | 判什么 |
|---|---|---|
| `15-render` | 产物 | 出片 |
| **still 对照** | 原版 + 产物 | **像不像 / 差在哪一层** |
| `16-blind-review` | 产物 + 判据 | 好不好(主观项, 换个人判) |

still 对照是**客观读数**, 盲审是**主观交叉验证**. still 给出的分区比值与包围盒,
应当作为盲审的输入之一  否则盲审只能靠"看着还行".
