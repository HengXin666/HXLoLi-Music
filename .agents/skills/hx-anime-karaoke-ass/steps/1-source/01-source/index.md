# 01 素材: 找完整版 MV 并清理画面

## 只做这一件事

拿到一份**完整版、≥1080p、无水印/无硬字幕**的 `base.mp4`, 并把它定为后续所有时间轴唯一的基准. 不碰歌词、不做设计

## 命令

```bash
hx-karaoke find_source.py "<番剧> <曲名>" --target <官方完整版秒数> --probe \
    --extra "<曲名> 完整版" --extra "<中文译名>"
```

它同时搜 **B 站官方搜索 API**(脚本自己拿 cookie)与 YouTube(yt-dlp), 按时长吻合度 / 分辨率 / 是否翻弹·钢琴·MAD 打分排序, `--probe` 补真实分辨率

## 判据(缺一条都不许往下走)

- **完整版**: 时长与官方 CD 音源一致(ED 常 3:30~4:30, TV size 约 1:29). 可用 lrclib 等歌词站 lrc 的最后一句时间做参照
- **分辨率 ≥1080p**. 720p 的字幕放到 1080p 时间轴上会糊
- **分数 ≥40**. 最高分 <40 时**停下来反问用户要链接**, 不许自己挑一个凑合  素材不行, 后面 17 步全白做, 比多问一句贵得多
- 水印/台标/硬字幕已去、首尾已淡入淡出

## 清画面

看画面**只用于去水印与确认素材质量**; 画面里的字**不作为歌词来源**(见 `steps/2-lyrics/02-lyrics`)

```bash
ffmpeg -ss T -i v.mp4 -frames:v 1 out.png       # 每 1.5s 抽帧拼 contact sheet 逐张看
```

- **定位水印时段**: 取一帧有水印的画面做掩膜(亮于局部均值的像素), 逐帧算「掩膜内 − 外圈」亮度差, >阈值即存在. 本手册 ED1 用此法找到 134.60–141.30 的 OP 曲名硬字幕、117–125/142–153 的 ニコニコ 水印
- **去除**: `delogo=x:y:w:h:enable='between(t,a,b)'`, 只在出现时段启用
- **录屏源上下带硬字幕**时改走 `crop` 裁掉再 `scale` 回 1920x1080
- 片头黑场/片尾 logo 记下时间, 留给标题卡与片尾卡; **MV 自带的标语不要在卡片里重复**
- 编码能力先自查: `ffmpeg -hide_banner -encoders 2>/dev/null | grep -E "libx264|libass"`. 两个都有就一个 ffmpeg 跑完; 缺 libx264 时用静态版 ffmpeg, 或走 `hx-karaoke render.sh` 的 rawvideo 管道

## 产物与过关条件

`proj/base.mp4`(清理后), 以及一份写下来的**片头黑场/片尾 logo 时间**(第 15 步卡片要用)
