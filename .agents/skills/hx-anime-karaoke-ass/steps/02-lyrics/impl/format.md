# 歌词标注格式(lyrics.txt)

一行一句: `时间 | 日文(带标注) | 中文`, `#` 开头为注释. 按 “ | ”(两侧带空格)切分.

```
00:26.586 | [愛|あい]のイロハを[学|まな]んでも | 纵然学会了爱的入门
00:39.140 | {(If you do)|いふゆーどぅ} なんだって[怖|こわ]くないから | 无论面对什么 我都不再害怕
02:26.281 | [貴方|あなた]のため？ | 是为了你？
```

| 语法 | 含义 | 对齐 | 显示 |
|------|------|------|------|
| `[漢字|よみ]` | **单个汉字**(推荐逐字标注: `[冒|ぼう][険|けん]`)| 按读音每个音拍 | 汉字 + 振假名, 注音居中在该字上 |
| `[世界|せ.かい]` | 多字词用 `.` 按字切分读音 | 同上 | 每个字各自注音(せ / かい) |
| `[今日|=きょう]` | 熟字训/义训(无法按字切分)用 `=` 前缀 | 同上 | 注音整体居中在词上 |
| `{Latin|かな}` | 英文和声等非假名片段 | 用假名读音对齐 | 原文(LAT 样式), 按音拍分段擦亮, 无注音 |
| かな / カナ | 每个音拍一个单元 | 片假名自动转平假名 | 原样 |
| 小假名 ゃゅょぁぃぅぇぉ | 并入前一拍(きゃ=1 拍)| | |
| 空格 | 词间空白 | 不计时 | 0.55em 间隔 |
| 全角/半角标点 | **仅显示, 不参与计时**(并入前一个单元) | | 随前一字高亮 |
| `（…）` / `(…)` 整句 | **合いの手/呼喊**(call)行 | 不参与 CTC 对齐与切窗; 按节拍给默认时间(`"call": true`), 需人工 fixes | 由特效函数自行呈现(如爆炸框逐个弹出), 不走主歌词层 |
| ` / ` | 一行里的长句拆成上下两段显示 | 与整行一起对齐 | PHRASES 中作为两句显示 |

注意:
- **振假名按汉字逐字标注**, 不要整词标注(用户明确要求; 整词注音在长词上会偏离对应汉字).
  来源站(UtaTen 等)给的是逐字 ruby 时直接照抄切分; 自己标注时查字典确认每个字的读音(促音/浊化归到对应字: `[逆|ぎゃっ][境|きょう]`、`[一|いっ][生|しょう]`).
- lrc 里把一整句副歌拆成两行、而别的段落是一行时, 要统一结构(合并或拆分一致), 否则 `--parity` 同句联合对齐无法配对.
- 读音以**实际演唱**为准(例: 「不順」唱 ふじゅん; 「貴方」唱 あなた; 「本気」唱 マジ 时要写 `[本気|まじ]`).
- 长音「ー」算一拍(对齐模型输出里有 ー).
- 同一句被唱成两段(中间有明显停顿/换镜)可拆成两行, 显示时再用 PHRASES 合并.
- 模型词表外的字符会被跳过并告警, 需改写读音.
