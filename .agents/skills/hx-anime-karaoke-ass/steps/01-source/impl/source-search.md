# 多源搜 MV: 评分口径与失败退化

## 为什么不能只用 `yt-dlp ytsearch`

实测: `ytsearch10` 返回的 10 条**全是 YouTube id**. B 站是番剧 MV 1080p 源的**大头**,
只用 YouTube 会直接漏掉它, 然后误判成「找不到完整版」.

## 命令

```bash
uv run $S/find_source.py "<番剧> <曲名>" --target <官方完整版秒数> --probe \
    --extra "<曲名> 完整版" --extra "<中文译名>"
```

它同时搜 **B 站官方搜索 API**(脚本自己拿 cookie)与 YouTube(yt-dlp),
按时长吻合度 / 分辨率 / 是否翻弹·钢琴·MAD 打分排序, `--probe` 补真实分辨率.

## 找完整版的搜索法

- B 站搜 `<曲名> 完整版 / full / PV / 高清 / 1080P`, 再按时长筛(与 lrc 末句时间 +10~20s 对比).
- TV OP 常只有 TV size: 找「OP 完整版 + 本篇剪辑」类视频.
- 录屏源带上下硬字幕时, 用 `crop` 裁掉再 `scale` 回 1920x1080(ヨスガノソラ OP 即此法), 或 delogo 分段.
- 偶像 MV(ED)可直接用官方 PV.
- 片头黑场/片尾 logo 记下时间, 留给标题卡与片尾卡.

## 失败退化路径(按顺序, 不许跳到最后一步)

1. **换检索词重搜一遍**: 日文原名 / 中文译名 / 罗马音, B 站与 YouTube 各一次.
2. **看候选表里分数最高的那几条**, 人工判它为什么低分(时长差多少、是不是翻弹).
3. **反问用户要链接**: 把候选表贴出来让用户选, 或直接问链接.
   **素材不行, 后面 17 步全白做** —— 这比多花两分钟问一句贵得多.

**不许**自己挑一个 720p 或 TV size 凑合往下做.
