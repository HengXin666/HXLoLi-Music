# 50 反推: 只有成品、没有生成器时怎么办

## 只做这一件事

拿到一份**别人做的成品 ASS**（几万条事件），要能说清"它是什么效果、怎么生成"，并在需要时**重放出来**。

上游的 `48-thread` 与 `49-generate` 是"自己设计"；这一步是"读懂别人"。两者的产物形态相同（ASS 事件），但**路径相反**：一个从意图到事件，一个从事件回到规格。

## 先分清你手上是哪一种

| 成品里有 | 是什么 | 怎么做 |
|---|---|---|
| `Comment:` 行带 `code` / `template` / `karaoke` | **模板程序的产物** | 走 `scripts/karetpl/`（直接执行，见 `impl/karetpl.md`） |
| 只有 `Dialogue:` 成品 | **生成器已被剥离** | 走本步骤：量规格 -> 重生成（见 `impl/reverse-spec.md`） |

判据一句话：

```bash
hx-karaoke scripts/karetpl/verify.py <成品.ass> --line <句首秒>
# 报 "没有 Comment 模板" = 走反推；报出逐字节命中数 = 走 karetpl
```

**别把两者搞混**。Charlotte ED 这份就是第二种  它有 70 行 `karaoke` 源句、5211 条成品，
但 `template`/`code` 段已被删掉，没有程序可执行。

## 反推的四步（顺序不能换）

1. **按样式分组量结构**，不是逐条读。9 个样式里通常 1~2 个占 90% 的事件量，
   先把它们量清，剩下的往往是同一套手法的变体

2. **量"一条事件里有哪些字段在变、哪些恒定"**。恒定的是规格，变的是参数：
   ```
   \an5 \blur3 \t(0,300)   <- 恒定，写进生成器
   \clip /\move /\t 内的值  <- 变化，要量出它的**取值分布**
   ```

3. **量的单位是"字段"，不是"事件"**。一条事件 200 字符，其中 `\an5` `\blur3`
   这类常量占一半  把它们剔掉，剩下的才是要复现的东西

4. **写生成器 -> 渲染 -> 看图 -> 对不上就回去量**。这一步不能跳（见下面的铁律）

## 两条铁律

### 1. 必须看实图，"像素量接近"会骗人

实测教训：反推 Charlotte 的 `OPCN` 时，我连续几轮报"像素量同量级、行为模式同步"，
而**实际画面是一片竖条糊影**（字的纵向范围 `y0-123`，原版是 `y18-69`）。

数字只能用来**定位**，不能用来**确认**。看图的顺序是：

```bash
# 先出对比帧（左右并排，裁到字幕带）
hx-karaoke scripts/qa/still_compare.py --ref 原版帧 --new 我的帧 --out 对比图 --crop <字幕带>
```

然后**你自己看图**。像素差 5% 可能是对的，差 0% 也可能全错（比如两边都是空白）。

### 2. 规格要从成品量，不要从常识猜

每一个数字都要有**出处与计数**。写进生成器的常量，注释里要写清"从哪几条量出来、几次印证"：

```python
# 实测 clip y 从 -70..130（中心30、高200）变成 -92..108（中心8、高200）
# **高度不变，中心随 \move 的终点一起平移**。写成"向外扩"会让字高变 242，
# 渲染出来就是纵向糊成一条（实测 y0-123 而原版 y18-69）。
```

判据：**规格表里每个数字，都能在成品里用 grep/sed 重新数一遍**。
数不出来的，说明还是猜的。

## 最容易漏的三处（都是实测踩过的）

1. **样式行要原样透传**。只取字体/字号/对齐，会把 `\3c`（描边色）、`bord`（描边宽）
   一起丢掉  实测漏掉后字没有辉光、笔画细一圈，而事件文本一个字都不差
2. **`PlayResX/PlayResY` 决定居中基准**。硬编码 1920 会让整句偏到画面外（实测偏 320px）
3. **同一样式内可能有多族手法**。Charlotte 的 `OPCN` 一个样式里就有
   `\fad(140,0)` 与 `\fad(0,140)` 两族，**时间窗也不同**（一族铺整句、一族只做 300ms 收尾）。
   当作一族处理会让事件数多一倍（实测 7872 vs 原版 2872）

## 随机量怎么办

含 `math.random` 的效果（粒子位置、图片选择）**不能逐字节对齐**。做法是：

- 先统计它的**分布**（范围、是否分档、与字序/句序是否相关）
- 生成器按同分布取样
- 验收改成**对分布**（条数量级、位置直方图），而不是对值

判据见 `impl/reverse-spec.md` 的「可复现性分级」。

## 过关条件

- 选一个**整句**（不是几帧）渲染 10 秒以上，左右并排出对比
- **看过图**（不是只看数字），且差异能逐条归因到规格里的某一项
- 规格表能重新量一遍，数字对得上
- 含随机的部分：说明它的分布，并声明"按分布等价，不按值"

## 交付物

```
proj/reverse/
├── spec.md        规格表（每个数字带出处与计数）
├── reverse_<样式>.py   量规格的脚本（可重跑）
├── gen_<样式>.py       按规格重生成的生成器
└── review/cmp/         左右对比帧 + 说明
```
