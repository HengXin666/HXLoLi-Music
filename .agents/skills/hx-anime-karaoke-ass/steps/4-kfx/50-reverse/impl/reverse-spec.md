# 规格实例: Charlotte ED 的 `OPCN`（反推）

**样本**：`static/music/Charlotte/Lia - Bravely You.ass`
`OPCN` 占 2872 条（全片 5211 条的 55%）。这份成品**没有 `template`/`code` 行**，生成器已被剥离，
所以走的是反推路线而不是 `karetpl`。

## 先看总量（决定先量哪个）

| 样式 | 条数 | 占 |
|---|---|---|
`OPCN` | 2872 | 55% |
`OPJP` | 1840 | 35% |
`OPJP-furigana` | 118 | |
`OPJP-C` / `OPJP-A` / `OPCN-C` / `OPCN-A` | 97 / 96 / 67 / 66 | |
其余 | < 60 各 | |

**先量 `OPCN`**：它占一半以上，量清它等于量清了主体。

## 样式与画幅（决定几何基准，最容易被忽略）

```
Style: OPCN,華康宗楷體W7,40,&H00FFFFFF,&H000019FF,&H0059B700,&H00000000,0,0,0,0,100,100,0,0,1,3,0,8,10,10,10,1
PlayResX: 1280    PlayResY: 720
```

三个必须原样保留的点：

1. **`\3c` = `&H0059B700`**、**`bord` = 3**  只取字体/字号/对齐会让字没有辉光、笔画细一圈
2. **`align` = 8**（顶部居中） 按底部对齐算 `middle` 会差 910px
3. **`PlayResX` = 1280**  居中基准是 640，硬编码 1920 会让整句偏右 320px

## 规格表（每个数字都能重新数一遍）

一个字 = **8 条**事件，两族结构同构、轴向不同：

| | 横切族 | 纵切族 |
|---|---|---|
条数 | 1436 | 1436 |
渐变 | `\fad(140,0)` | `\fad(0,140)` |
缩放 | `\fscx240`（在 `\t` **外**） | `\fscy240`（在 `\t` **内**） |
clip 初始 | x **整块**（跨 200） | y **整块**（`-70~130`，高 200） |
clip 撕裂 | y 撕成 `(-70,20)(20,30)(30,40)(40,130)`，各 **359 次** | x 撕成 **90\|10\|10\|90**，各 **718 次** |
`\t(0,300)` | x 收拢到**字心** | clip 与 `\move` **整体平移**（高度恒 200） |
`\move` | 起点错开 → 终点字心 | 起点字心 → 终点 y 平移后的中心 |
**时间窗** | **[句首, 句末]** 铺满整句 | **[句末, 句末+300ms]** 只做收尾 |

共同常量：`\an5 \blur3 \t(0,300)`

### 复现这三个数字的命令

```bash
# 两族条数各 1436
grep -c 'Dialogue:[^,]*,[^,]*,[^,]*,[^,]*,[^,]*,[^,]*,[^,]*,[^,]*,[^,]*,[^,]*,[^,]*,OPCN' 成品.ass

# 横切 y 带 4 段各 359 次 / 纵切 x 带宽 90|10
# 见 reverse_opcn.py 的 summarize()  13 条判据一次跑完

# 样式与 PlayRes
grep -E '^Style: OPCN,|^PlayRes' 成品.ass
```

## 色是句级的，四色轮换

```
第1句 坍塌终结的世界      → BA4561
第2句 无情地宣告          → 672791
第3-6句 独自一人/你/听到了/什么 → A06E31
第7-10句 我/看到了/遥远的/幻梦  → BA4561
```

四色固定为 `BA4561` / `672791` / `45C043` / `A06E31`，按句轮换。
（"同句多色"的观测是**相邻句时间重叠**造成的，不是逐字变色。）

## 整句 7 个字**同时出现**

实测「坍塌终结的世界」7 个字的事件**全部从 7.10 开始**，时间窗完全相同。

**逐字高亮不是 `OPCN` 的职责**  那是 `OPJP` / `OPCN-A` 的事。
把 `OPCN` 按音拍切时间窗会让画面变成"逐字累加"（实测 1713→25505），
而原版整句恒定 15584。

## 复现结果

```
t=7.60  原=15584  我=15584  比=1.00
t=9.60  原=15584  我=15584  比=1.00
t=14.10 原=10738  我=10738  比=1.00
t=17.10 原=10738  我=10738  比=1.00
```

21 帧里 19 帧像素量精确一致。唯一 1.87 的是 13.6s（**换句交界**，两句时间重叠）。

## 可复现性分级

| 级别 | 判据 | 本例 |
|---|---|---|
**逐字节** | 事件文本完全相同 | 不可达（成品无生成器，只能重生成等价事件） |
**逐像素** | 同刻帧的像素量一致 | **19/21 帧达成** |
**分布等价** | 条数量级、直方图一致 | 含随机的段用这一级 |

`\move` 的起点偏移与 `\t` 的平移量在原版里是**逐字变化**的（`-20/25/-18/-22` 这类）。
本实现用的是实测范围里的代表值  要走到"分布等价"仍需把它做成按分布取样。

## 迁移到别的样式时

`OPJP`（1840 条，35%）还没做。它的结构是另一套：

- 大部分是**文字行**（`\pos` + `\t` 缩放 + 字）
- 少数是**绘图行**（`\p1` + 路径 + `\blur6`）
- 还有 26 条**空标签行**（`{\p1}×8`） 疑似模板残片，**不要当成有效事件**

方法相同：先按样式分组量结构，再量"哪些字段恒定、哪些在变"，然后是老规矩
**写生成器 → 渲染 → 看图 → 对不上回去量**。
