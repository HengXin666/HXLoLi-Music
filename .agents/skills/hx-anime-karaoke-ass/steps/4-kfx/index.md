# 4 字幕特效设计制作

## 这一组是整条链路的重心

前面三组(素材/歌词/考据)产出的都是**输入**; 后面一组只做**拦截**.
**观众能看到的东西全部在这一组里产生** —— 所以它是唯一被拆成十个子步骤的组.

## 子步骤

按顺序做. 每个 `<key>` 对应目录 `steps/4-kfx/<key>/`, 其 `index.md` 是那一步的契约.

| 子步骤 | 关心什么 |
|------|---------|
| `40-music-events` | 从伴奏抽卡点网格(十六分/八分)、起音、低频峰、段落边界 |
| `41-channels` | 清点**副文本通道**: 振假名/译文/和声/唱者标注 各有没有、各自的时间逻辑 |
| `42-text-main` | 主文本层: 出现 / 消失 / 逐字 / 字词组关联 / 意象 |
| `43-text-sub` | 副文本层: 按通道各写各的, 不与主文本共用时钟 |
| `44-beat` | **卡点层**: 跟音乐事件的脉冲层(不跟字) |
| `45-bg` | 背景层: 镜头 / 情感 / 番剧符号 |
| `46-image` | **图片层**: 抠图 + `\1img` 嵌入, 左右元素在卡点出现 |
| `47-color` | 色彩系统: 段落色系 / 声部色 / 句内折返 / 背景跟随 |
| `48-thread` | 句间关联: 跨句状态传递表 |
| `49-generate` | 把上面九步翻译成生成器, 出 `out.ass` |

## 五层的时钟必须分开

这是本组的**地基**, 定错了后面全是在一个层里叠图形:

| 层 | 时钟来源 | 段落间是否停 |
|---|---|---|
| 主文本 | 人声音拍 | 停(跟句) |
| 副文本 | 各通道自己的逻辑 | 按通道 |
| **卡点** | 音乐事件网格(十六分) | **不停** |
| 背景 | 镜头切换 | **不停** |
| 图片 | 卡点时刻 | 停(少量) |

**存在感曲线也相反**: 卡点是脉冲(窄峰、高), 背景是平坦(宽、低).
合成一层会让"空气"和"脉搏"互相吃掉 —— 这就是必须分成两组的原因.

## 一条不许破的边界

**卡点层不许长成"字".** 它是伴奏触发, 必然与人声错位; 一旦看起来像文字,
观众会拿它判断"唱到哪了", 结果是觉得字幕错了. 它只做光/粒子/形变/位移.

## 这一步要用的脚本

- `<skill>/scripts/music_events.py` - 伴奏 → 卡点网格与事件表 (`40`)
- `<skill>/scripts/voices.py` - 声部归属检测, 供句内配色 (`47`)
- `<skill>/scripts/scene_timeline.py` - 从 MV 抽帧算镜头段与逐秒主色, 驱动背景层 (`45`)
- `<skill>/scripts/assfx/bg.py` - 背景层发射器 (`45`)
- `<skill>/scripts/cutout.py` - 抠图 + 边缘体检 (`46`)
- `<skill>/scripts/render_octopus.py` - **真正的渲染器**(定制版 libass), 目检与迭代 (`44`~`49` 都要)
- `<skill>/scripts/assfx/beat.py` - 卡点层发射器 (`44`)
- `<skill>/scripts/assfx/image.py` - `\1img` 图片层 (`46`)
- `<skill>/scripts/assfx/color.py` - 段落色系 / 声部色 / 折返点 (`47`)
- `<skill>/scripts/assfx/` 其余 - 生成库, 逐模块说明见 `49-generate/impl/library.md`
