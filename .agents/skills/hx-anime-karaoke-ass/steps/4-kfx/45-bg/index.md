# 45 背景层设计(镜头 / 情感 / 番剧)

## 只做这一件事

铺一层**不挂任何字**的层, 由三样东西驱动: 该秒的 MV 画面、该段的情感、番剧符号.
它是"空气", 存在感最低, 但**跨句不停**.

## 与卡点层的分工(别合成一层)

| | 背景层 | 卡点层 |
|---|---|---|
| 曲线 | **平坦(宽、低)** | **脉冲(窄峰、高)** |
| 时钟 | 镜头切换 | 音乐事件网格 |
| 意图 | 空气 / 质感 | 情绪强度 |
| 触发 | 画面 + 情感 + 番剧符号 | 伴奏 |

合成一层会让"空气"和"脉搏"互相吃掉 —— 这是两组必须分开的数学理由.

## 三个驱动源

| 源 | 从哪来 | 变成什么 |
|---|---|---|
| **MV 场景** | `review/scene_timeline.md` 的抽帧时间线 | 该秒的主色 → 背景色温; 亮度 → 背景明暗 |
| **情感** | `anime.notes.md` 的情绪曲线 | 段落等级 L0~L3 → 背景的量与速度 |
| **番剧符号** | `anime.elements.md` 的 A 级元素 | 背景里反复出现的**同一个符号**的变体 |

## band 铁律不变(先读这条, 否则白做)

背景层**只能**在 band 内. 实测专业参考也一样:
东方「轨迹さえ」42872 条事件全部落在 **y 856~972** 的 116px 横带里, x 372~1392 ——
**没有一条铺到画面中部**.

所以"背景贯通全曲"的正确形式是:

1. **图形与配色在全曲层面统一**(不是每句换一套);
2. **覆盖率铺到句间空隙**(不是跟着句子开关);
3. 单条事件仍然短(0.5~1s), **不要靠超长事件跨句**.

实测参考的覆盖率: `Ptcl` 逐秒 **61%**, `Flow` **78%**; 跨句事件只有 **1.2%**.
它靠覆盖率与统一性做到"贯通", 不靠长事件.

## 过关条件

- **逐秒覆盖率 ≥55%**(句间空隙也要有事件). 判据: 把背景事件的存活区间按秒展开, 看零事件秒的占比.
- **图形种类在全曲层面受控**: 核心图形 2~4 种 + 每 10~20s 引入一个变体.
  不是每句换一套(那会失去统一性), 也不是全曲一种(那是 `impl/density.md` §1b 的"没分层").
- 目检: 背景不盖住文字带; 句间空隙里背景仍在动.

## 与 `42-text-main` 的"意境背景"的区别

`three-layers.md` 里的"意境背景"是**格子内部**的氛围(十种通用氛围, 只读歌词).
这里的背景层要读**镜头 + 情感 + 番剧符号**三个源. 前者是后者的一个子集 ——
有镜头数据时用后者, 没有时退回前者.
