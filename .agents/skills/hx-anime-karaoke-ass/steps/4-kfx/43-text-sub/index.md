# 43 副文本层设计

## 只做这一件事

给 `41-channels` 里判为"有"的**每一条通道**, 各写一条时间逻辑. 产物写进
`proj/review/design-table.md` 的副文本列.

## 为什么必须按通道分开写

**中文行与振假名不是一个东西.**

| 通道 | 依附 | 出现时机 | 有逐字吗 |
|---|---|---|---|
| 读音(振假名) | **单个汉字** | 跟宿主字的高亮 | **有**, 按音拍点亮假名 |
| 语言(译文) | **整句** | 跟"这句话译完了", **与音拍无关** | **没有**(不被唱) |
| 声部(和声/call) | **它自己的音拍** | 跟它自己的起音, 常与主文本重叠 | 有 |
| 标注(唱者) | **段** | 跟"换人"那一刻 | 没有 |
| 画外(台词) | **画面台词点** | 跟台词时刻 | 没有 |

## 三条纪律

1. **不许共用时钟.** 每条通道的 `出现 / 逐字 / 消失` 各自定.
   现在的问题是 33 句全走默认(`rb_ent` 晚 0.06s / `cn_ent` 晚 0.20s), 结果"一句里全都在同时动".
   判据: **副文本的出现时刻在整首里要有至少 3 个不同取值** —— 全曲同值 = 从没设计过.
2. **语言通道不许做逐字.** 它不被唱, 没有逐字时间; 硬做会与主唱错位.
   它可以做的是**整句的进退场**与**与主文本的相对先后**.
3. **副文本与主文本要"有所区别", 但不是轮换.**
   用户 2026-10-03 原话: 「副文本的话, 你就可以跟主文本有所区别, 注意是有所区别.
   你不能也是指把它搞成轮换的来, 这样子就不对了, 你也要有自己的设计美感.」
   区别靠三样: **字号 / 位置 / 出现时机**, 不靠"换个颜色循环".

## 色彩上的区别怎么给(与 `47-color` 配合)

- 主文本: 填充近白 + 彩色描边(遵守 `doc/KFX-RULES.md`)
- 副文本: **降低存在感**——同一色族但明度更低 / 描边更细 / 不参与逐字游走.
  它不是"另一套颜色", 是"同一套颜色的弱化档". 这样它不抢主文本的读点.

## 过关条件

见 `impl/design-table.md` 的 15 格判据: `副·出现` 取值 ≥3 种、`副·逐字` 填写率 ≥50%.
