# 48 句间关联(跨句状态)

## 只做这一件事

让相邻句之间**共用一个视觉变量**, 使整首读作连续体而不是 N 个独立片段.

## 症状(实测本工程, 33 句)

| 量 | 实测 |
|---|---|
| fx 首事件 == 该句 band 起点(±0.05s) | **31/33** |
| fx 末事件 == 该句 band 终点 | **33/33** |
| 每句图形种类(按绘图路径 md5) | 中位 **4**, 最小 1 |
| 每句 fx 事件数 | 中位 **80**(参考量级 OP=19/ED=17 的 4.4 倍) |
| fx 终点晚于下一句 band 起点 | 31.3% |

**六条边里四条在动, 但整段读起来是 33 个独立片段** —— 每句的视觉变量生命周期被钉死在本句.
这不是密度问题(密度已是参考的 4 倍).
那 31.3% 跨句事件只是 `Generator` 的**退场淡出尾巴**(α 在降, 颜色/位置/图形全不变),
**不携带任何变量**.

## 五种可核对的承接类型

| 类型 | 机制 | 可机械判的量 |
|---|---|---|
| **节奏承接** | 前句末音拍间隔 = 后句首音拍间隔 | `timing.json` 相邻音拍间隔 |
| **语法承接** | 否定/递进/呼应的标志词, 图形在前句末尾就**反向准备** | 事件是否跨过句边界且**量发生了变化** |
| **意象承接** | 同一元素在相邻句之间**加高一级 / 转角度 / 换色** | 占比/渐变/色相的差 |
| **位置承接** | 前句退场方向 = 后句入场方向 | 退场与入场位移向量同号 |
| **色温承接** | 一段共用一个色系, 句内只做深浅差 | 段落内色相集中度 |

**注意**: 意象承接 ≠ 意象重复. 同一元素**加高一级**是承接; 原样再用一遍是偷懒.

## 真正的连续性由"层"提供, 不由"句子"提供

这是最容易走偏的一点. 参考成品里句与句之间那个"缝", 是被**跨句不停的层**填住的:

- **卡点层**(`44-beat`)与**背景层**(`45-bg`)跨句不停 —— 它们不跟着句子的生死走;
- 主文本层与副文本层跟句, 但它们可以把末位置/末色留给下一句.

**所以 `48` 的第一件事不是"给相邻句加一条连接线", 而是确认卡点层与背景层没有跟着句子断.**

## 状态表(产物)

`proj/review/design-table.md` 里的 `承上` / `启下` 两列, 每句各一格:

```
| 句 | ... | 承上 | 启下 |
| 24 | ... | 黑幕颜色 = 上一句结尾留在右缘的暗色, 色相 -8° | 黑幕散去后留一条向右的动量 |
```

**硬规则**: `承上` 的变量必须能在上一行的 `启下` 里找到**同名**的那一项.

## 写之前过一遍

1. 本句开头**有没有一样东西是从上一句带过来的**? 是哪个变量(位置/颜色/图形/动量)?
2. 本句结尾**留下什么给下一句**? 不写就是零.
3. 退场方向与下一句入场方向一致吗?
4. 全曲的"核心图形"是哪几个? 每 10~20s 引入什么变体?
5. 段落色系边界在哪一秒? 跨过边界时色相真的换了吗?

## 过关条件

见 `impl/design-table.md`: `承上` 与上一行 `启下` 有同名变量的行 **≥60%**.
