# 番剧卡拉OK 特效字幕 (ASS)

目标: 一条完整非常用心的字幕组做的, 堪比PV的特效歌词 ASS

歌词卡得准 (每个音拍落在音符起音上), 排得稳 (注音贴字, 中文不抢画面), 特效有意义 (每句都能说出对应哪个镜头 / 哪句词义 / 番剧的哪个设定), 不越界 (只在字幕附近 5%)

先读 `shared/hard-rules.md` - 十条跨步骤铁律, 违反任一条都要返工

脚本, 模板与示例都不在本文件里列: 走到哪一步, 那一步的契约会点名它需要的脚本与参考文件

跑任何脚本一律 `hx-karaoke <脚本>`, 禁止裸 `python` 与 `uv run`:

```bash
hx-karaoke --check # 体检环境/字体, 缺什么会列出来
hx-karaoke scripts/setup_env.py # 缺什么补什么 (幂等; 一条命令, 不需要判断装不装)
```

工程一律放 `dev/<番名>/<歌曲名>/`, 做完搬到 `static/music/<番名>/`并跑一次 `bash make.sh`; 详见 `steps/00-setup/index.md` 的「工作区」与「发布」两节。

## 步骤表

按顺序做. 下表每个 `<key>` 对应一个目录 `steps/<key>/`, 其 `index.md` 就是那一步的契约(只做什么 / 命令与脚本 / 判据 / 产物 / 过关条件), 同级 `impl/` 放本步可插拔的做法, 契约会点名何时读它

| 步骤 | 关心什么 |
|------|---------|
| `00-setup` | 环境(一条命令) + 字体 + 算力设备 |
| `01-source` | 完整版 1080p, 水印干净 |
| `02-lyrics` | 来源定级 + 标注 + 读音基准 |
| `03-offset` | 网络时间轴与这份视频差多少 |
| `04-vocals` | 分出人声与伴奏 |
| `05-align` | CTC 音拍级强制对齐 |
| `06-kf-timing` | 网络逐字定形状 + 本地定平移 |
| `07-grid` | 节拍网格与吸附 (含 07b 重对齐) |
| `08-review-timing` | 人工校时 + 时间轴体检 (会非零退出) |
| `09-ruby` | 注音高度实测 |
| `10-anime-bg` | 原作内涵 + 番剧元素表 |
| `11-design` | 逐句特效设计 |
| `12-generate` | 把设计表翻译成生成器 |
| `13-validate` | 门禁 + 自动校验 + 可见性 |
| `14-inspect` | 抽帧目检 |
| `15-render` | 封装出片 |
