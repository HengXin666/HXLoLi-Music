# 無職転生 设定与母题（ED1「オンリー」）

来源：`anime.background.json`（bgm.tv 条目 277554「无职转生～到了异世界就拿出真本事～」，2021-01-10，41 位角色简介）+ 萌娘百科正文。

## 故事前提

34 岁、童贞、无职的家里蹲，在父母葬礼当天被赶出家门，随后被卡车撞死。
意识清醒时他已成为剑与魔法世界里的一个新生婴儿 —— **鲁迪乌斯·格雷拉特**。
前世像废物一样活过的男人，发誓“这次一定要认真地活”。

## 主题

**“第二次的人生，这次认真活”**，以及“认真活”具体长什么样：学会走路、学魔法、交到第一个人、
成为谁的学生、成为谁的丈夫与父亲。
曲名「オンリー」= 对“唯一的你”的告白 —— 但歌词里的对象随时间移动（师匠 → 家人 → 唯一的她），
特效要跟着这个移动走，不要固定成一段恋爱。

## 画面时间线（MV 是回忆蒙太奇）

出生 → 学步 → 旅途 → 战斗 → 魔法课（洛琪希） → 家人/餐桌 → 离别。
**每句特效必须落在“当句对应的那一段回忆”上**，不是随机贴图形：
- 出现“学 / 教 / 知识”→ 书页、烛火、符文（洛琪希线）
- 出现“破坏 / 愤怒 / 决意”→ 裂纹、碎片、刀光（艾莉丝线的战斗镜头）
- 出现“守护 / 想要保护”→ 地面魔法阵 + 盾（瑞杰路德线与塞妮丝线）
- 出现“唯一的你”→ 红线（贯穿全曲的收束）

## 判据

- 设计表里每句的母题要能对上“画面时间线”的一段；对不上的标为氛围句。
- “想要破坏 / 想要守护”这对矛盾句用**同一骨架、互换材质**（红白裂纹 vs 蓝白魔法阵），
  观众应能认出“又是这句、但相反了”。
