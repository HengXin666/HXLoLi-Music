# 本地特效歌词: 取其精华, 去其糟粕 (2026-11-24 盘点)

仓库里 `static/music/` 和 `dev/` 已有二十多份特效 ASS. 来源不同, 质量差很远. 做新歌前先读这页: 学人做的方法, 避开 AI 做坏过的地方. **学方法, 不抄动作和数值.**

## 人做的好在哪 (精华)

都是从模板源码与实渲染帧里读出来的, 不是印象.

1. **一首歌一个贯穿的主题物件, 当句子的"框", 不到处飞.** ファティマ: 每句左右各一个齿轮, 随整句时长转一圈 (`\t(0,$ldur,\frz360)`), 全曲不换 (命运石之门 = 齿轮). ポポロン: 句首挂一个钟表 (底盘, 指针按句长转), 兔子 Tippy 的剪影由粒子拼出. 物件少, 一眼认得出是哪部番, 位置固定在句子两端或句首.
2. **分段换模板, 段落就是风格单元.** 羽ばたき / INNOCENT BLUE 的样式名 `OPJP, OPJP 2, OPJP 3-1, OPJP 3-2`; モノクローム 的 `JP_V1, CN_CHO1, CN_CHO2, CN_CLI, CN_FIN` = 主歌, 副歌 1/2, 高潮, 结尾. 每段一套颜色与动作, 段内一致, 换段才变.
3. **颜色有意思: 按演唱者或按段落.** ポポロン 的 `code` 行 "应援色": 按 `line.actor` (chino / maya / megu, 即チマメ隊三人) 给每人一种颜色. モノクローム 每段一个主色 (灰, 天蓝, 绿, 粉, 红). Bravely You 每句一个描边色.
4. **词级意象只给少数词.** モノクローム 在「影」上放天使光环; 羽ばたき 在 "シンフォニー" 前拉一条心电图. 其余字只做基础亮字. 物件是给 "这个词" 的, 不是给 "这一句" 撒的.
5. **每个音节三层, 时间全跟音节.** 进 (`start2syl`: 字纵向 130% 落回 100%, 淡入), 唱 (`syl`: 放大 130% 再回, 描边转白; Bravely 加一颗星芒 + 两圈涟漪, 时长 = 音节时长), 出 (`syl2end`: 200 ms 淡出). 粒子 `loop 5` 从当前音节冒出. 没有和音节无关的动画.
6. **克制.** Bravely You 整屏同时只有一处在动 (正在唱的那个字的星芒与涟漪), 其余字静止可读; 中文小一号, 不抢.

## 做坏过的地方 (糟粕, 以后当门禁看)

1. **照搬别首歌的整套特效.** INNOCENT BLUE (歌名是天空与蓝) 用了 羽ばたき (生日, 翅膀) 的藤蔓和花: 漂亮, 但和这首歌无关. 和 skill 第 1 条 "换到别的歌也成立的意象不算意象" 是同一件事.
2. **未唱的字暗到读不出.** ツナグキズナ (static 版) 未唱字是深灰字配深色描边, 在暗底上几乎看不见, 整行像没出现. `doc/KFX-README.md` 早有判据: 暗态对比 ≥ 3:1.
3. **换句时中文两行叠在一起.** adrenaline!!! 换句瞬间新旧两行中文落在同一位置交叉淡化, 一帧里两行字压在一起 (36 s, 80 s 处). = skill 第 3 条 "不压字".
4. **AI 第一代全是同一套: 光晕底 + 浮尘 + 渐亮.** 读得清, 但每首都一样, 没有一个物件能看出是哪部番. 好看不等于有设计.
5. **发布目录里放草稿.** `v5预览`, `_` 前缀备份, 两份同内容的 东方 ASS. 前端播放列表会扫到; 草稿放工程 `backup-*/`.

## 落到我们的做法

- 设计稿先写三样再写逐句: **主题物件** (全曲一个, 框在句子上, 番里认得出), **段落表** (每段一套颜色与动作, 段内不变), **配色规则** (按演唱者 / 按段落, 写清为什么).
- 词级意象写在补丁上 `[词]{...}`, 一首歌只给少数词; 物件全曲每件一次 (ろりこん 已有的规则).
- 每个字的进 / 唱 / 出都跟音节时间, 动的只有正在唱的地方.
- 拿不准时去看人做的那几份的模板源码 (`Comment:` 行), 学它的结构; `steps/4-kfx/50-reverse` 讲怎么读.
