# 门禁标定记录 (硬规则 10b)

新门禁转 FAIL 之前, 先在真实成品上量分布, 记在这里. 每节写: 样本 / 分布 / 定的分界 / 正反例结果.

## 跨作品特效指纹 `scripts/kfx/fingerprint.py` (2026-11-17)

量法: 6 组分布 (标签频次 tags / 绘图几何 geom / 层分布 layer / 寿命 life / 运动 motion / 色相 hue) 各取余弦, 取均值.
样本: `static/music/` 下 16 份已发布 ASS + 示例新出片, 两两 136 对.

| 分组 | 对数 | 值 |
|------|------|----|
| 同一外部模板批量出的不同歌 (天使の3P INNOCENT BLUE / 羽ばたき) | 1 | 0.999 |
| 本地 AI 产线出的不同歌, 最高三对 (比翼 / オンリー; dmp☆ / TrySail; トコハナ v5 / TrySail) | 3 | 0.969 / 0.961 / 0.901 |
| 同一首歌两版 (トコハナ 定稿 / v5; オンリー 发布 / 示例新出片) | 2 | 0.868 / 0.913 |
| 本地 AI 产线其余不同歌对 (pos.txt 8 份之间) | 25 | 0.70 ~ 0.87 |
| 涉及外部人工作品的不同歌对 | 其余 | 0.069 ~ 0.69 |

分界: **>= 0.95 FAIL** (近似换词套用: 外部批量模板 0.999 与本地两对 0.96 以上), **0.85 ~ 0.95 WARN**, 以下 OK.
正例 (不许 FAIL): 同一首歌两版之外的 133 对不同歌全部 < 0.95. 反例 (必须 FAIL): 0.999 / 0.969 / 0.961 三对.
限制: 本地产线出的歌彼此普遍 0.7 以上, 分界只能抓 "几乎同一套", 抓不到 "同一种手法"; 只说长得像, 不说好坏.
两首新歌互比的实测待第二首 (见 known-gaps 跨曲基线 B7).
